## 🚀 Featured projects

### ☸️ [IoT Data Platform on Kubernetes](https://github.com/josedimas23/iot-k8s-data-platform)
*Bachelor's thesis · University of Granada*

Scalable IoT platform running on Kubernetes: simulated sensors stream data into **CrateDB** through a **Flask REST API**, **Grafana** dashboards show it in real time, and the **HPA** autoscales the services under load.

### 🌐 [High-Availability Web Farm](https://github.com/josedimas23/web-server-farm)
*Server infrastructure*

Containerized web farm built for availability: **Nginx** load balancing across **Apache** backends, **HTTPS**, an **iptables** firewall, and load testing with **ab** and **Locust** to measure how it holds up.

Mobile app that helps special-education students complete tasks on their own, guided step by step with **pictograms**. Teachers create and assign tasks; students follow them in an interface designed for accessibility.
